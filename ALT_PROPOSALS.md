# Propositions d'alt — vignettes de la grille de la home

Source : HTML de production de https://gilanselmi.com/ (récupéré le 2026-11-18) ; item #12 de SEO_AUDIT.md. Les images ont été réellement regardées (vignettes 384 px) ; les vidéos sont hors périmètre.

**Règles de saisie dans Storyblok**
1. Champ à renseigner : `alt` du bloc `media_item` (prioritaire dans lib/gallery-items.ts, ligne `blok.alt || blok.media?.alt || blok.title`) ; à défaut, l'alt de l'asset, puis le titre.
2. Saisir l'alt proposé tel quel, sans espace final, sans majuscules de cri ni mots hors sujet ; ne pas toucher au titre (il sert aussi de légende).
3. Les alt sont en anglais ; format « client — type, sujet factuel, photographed by Gil Anselmi » ; la mention du photographe est omise sur les images secondaires d'une série.
4. Toute ligne contenant « [à compléter] » exige une information du photographe (client) avant saisie ; ne jamais saisir le marqueur tel quel.
5. Les lignes signalées doublon pointent la même image : renseigner le même alt (ou retirer le doublon de la grille) ; les remarques « à vérifier » indiquent un écart entre l'alt actuel et ce que l'image montre.

Les noms de modèles, stylistes, lieux et clients ne sont jamais déduits des noms de fichiers : seuls ceux déjà présents dans l'alt/titre actuel, ou lisibles dans l'image (texte/logo incrusté), sont repris.
